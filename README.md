# 食堂混雑状況表示アプリ

食堂の混み具合やメニューの販売状況を、ブラウザから確認できるWebアプリです。
現在の利用人数と混雑度に加えて、10分後・20分後の混雑予測も確認できます。
食堂へ行く前の状況確認や、管理者による食堂情報の更新に使えます。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 混雑状況の確認 | 現在人数・利用率・混雑度・最終更新日時を表示 |
| AIによる人数計測 | カメラ映像から人物を検出し、利用人数を自動計測 |
| 混雑予測 | 計測履歴から10分後・20分後の人数を推定 |
| メニューの販売状況 | カレーライス・ラーメン・唐揚げ定食・日替わり定食の販売中／売り切れを表示 |
| お知らせ | 食堂からの案内を表示 |
| 自動更新 | 新しいデータを自動で取得 |
| 管理者機能 | ログインした管理者が人数・販売状況・お知らせを保存 |

## 混雑度の見方

食堂の定員は**40人**を基準としています。
利用人数から利用率を計算し、3段階で混み具合を表示します。

| 利用率 | 表示 |
| --- | --- |
| 30%未満 | 🟢 空いている |
| 30%以上・70%未満 | 🟡 普通 |
| 70%以上 | 🔴 混雑 |

## 使い方

### 利用者

混雑表示画面を開くと、ログインせずに混雑状況・予測・メニュー・お知らせを確認できます。
画面の情報は自動で更新されます。

### 管理者

1. 画面上部の「管理者画面」からログインします。
2. 「カメラで人数を計測」を押し、ブラウザのカメラ使用を許可します。
3. 自動保存を有効にすると、計測中は30秒ごとに人数を保存します。保存ボタンでも更新できます。
4. メニューの販売状況やお知らせを編集し、保存します。
5. 「混雑表示」へ戻り、更新した内容を確認します。

人数はカメラで計測します。現在人数の手入力欄はありません。
カメラ停止中でも、保存済みの人数を保ったまま販売状況とお知らせを更新できます。
管理者アカウントは運用担当者が管理します。

## AI計測と混雑予測

人数計測には、TensorFlow.jsとCOCO-SSDを使用し、カメラ映像内の人物を約3秒ごとに検出します。

混雑予測には、実測した人数の履歴を使う統計モデルを使用します。
直近の人数の増減から予測し、過去の同時間帯の履歴が十分にあれば、曜日や時間帯の傾向も反映します。

- 約5分間の計測・保存がたまると、短期予測を表示します。
- 過去28日間から、対応する同時間帯の履歴が3日以上そろうと、その傾向も使います。
- 履歴が足りない場合は「予測データ不足」、計測が止まった場合は「計測待ち」と表示します。
- 予測値は0〜40人の範囲です。実測が40人を超えた場合も、現在人数は実際の値を保持します。

予測は目安です。授業の予定やイベントなどによる急な変化は、予測に反映されない場合があります。

## カメラ映像と保存データ

カメラ映像は端末内で処理し、画像や動画をサーバーへ送信しません。
保存するのは、人数・販売状況・お知らせ・更新日時などの表示用データです。
データの閲覧は公開し、更新は管理者に制限しています。
